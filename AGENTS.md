# Collection conventions

- All photographs in this repository were taken by **Yuval Kolodkin-Gal**
  (`@yuvalkolodkingal`). Preserve that credit in the README, gallery, and exports.
- Use local photographic tools for exposure, color, contrast, and crops. Preserve
  the photographed scene; do not use generative redraws unless Yuval asks for them.
- Keep source photographs and existing editing sidecars untouched. Record edits
  in `metadata/recipes.json`; export only into repository output directories.
- Do not upscale photographs. Keep wallpaper exports at 16:9, with source-sized
  masters capped at 3840×2160 and a 1920×1080 version.
- Run `uv run scripts/verify_collection.py` after changing exports or theme links.
- Theme installation and activation are separate actions. Repository changes do
  not authorize changing the running desktop.
